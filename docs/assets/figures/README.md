# 网页主图来源

这里只发布论文五张主图的完整网页导出，不包含论文 PDF、论文目录或补充材料包。
图片以 2400 px 宽度无损导出为 WebP，未裁切、重画曲线或修改标注。
图内保留论文英文标注；网页提供中英文图注和替代文本，并可打开原尺寸图片。

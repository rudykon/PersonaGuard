# 论文叙事改版对应与检查

本轮依据本地论文 `main.tex`、`body.tex` 及其生成表格重组网页。
论文正文只作为内容依据；公开内容仍为网页、经允许的独立图表、代码与既有公开结果。

## 页面栏目与论文章节

| 页面栏目 | 对应论文章节 | 页面承担的论证任务 |
|---|---|---|
| Overview / 研究概述 | Introduction + Background and Related Work | 正式标题、短摘要、研究缺口、原 RQ1–RQ3 与三项贡献 |
| Method / 方法 | Evidence-to-Action Audit Protocol | Fig. 1；用途、证据记录、来源、规则、行动、责任与复审；有符号校准 walkthrough |
| Evaluation / 评价设计 | Evaluation Methods | Fig. 2；区分协议评价与连续情感案例中的证据生成 |
| Results / 研究结果 | Results 的四个小节 | 依论文顺序呈现协议行为、解释边界、增量证据与行动综合 |
| Discussion / 讨论 | Discussion + Conclusion | 方法增量、信息匹配与生命周期启示、局限、后续验证和结论 |
| Resources / 资源 | Data and Code Availability 的公开部分 | 代码、正式规则、公开结果、复现指南；不提供未公开论文下载 |

## 文案及模块迁移

- 正式论文标题由页尾移至首屏；取消首屏画像保留预告。引导问题“AI 何时应该进行个性化？”移入研究动机。
- 增加压缩后的研究缺口、论文原有 RQ1–RQ3 及三项贡献，保留论文的问题体系。
- 五个问题保留为方法区的规则解释；补齐用途定义、证据状态与行动的区别、来源追溯、责任与复审。
- 方法中的短示例改用 `signed_calibration`，说明 R3 为什么先于 R1 决定行动。
- 原“检查与局限”分为评价设计、协议结果和讨论；明确四条工作用途与七条外部作者编码用途的关系。
- 恢复画像测量、估计器与参考敏感性、标量传感和有符号校准证据。额外轨迹分析保留各自的信息、单位和对照，不增加正式路线或合并成模型排名。
- 四案例交互移入结果综合，按画像解释、可选传感、部署校准、保留迁移排序；默认画像解释。综合表不依赖点击即可阅读，手机端逐条显示。
- 复审摘要依据论文生成表格和已有规则要求；正式责任角色与触发条件直接连接 `results/evidence_traceability.json`，不新增证据判断。
- 主要发现、五张主图及必要数值默认可见。原始字段、执行细节、额外敏感性说明和命令继续折叠。

## 数据与公开范围

- 唯一数值来源仍为 `results/revision6_source.json`。网页主要指标复用论文数值生成函数，`data-number` 静态内容与生成数据共同检查。
- 正式规则、案例输入、结果源、绘图源与解析器共 38 个文件的摘要均未改变。
- `cases.js` 由构建脚本重新生成，没有手工改写判定；新增的是来源中的责任与复审字段、网页所需的数值。
- 规则顺序仍为 R4 → R2 → R3 → R1 → R5。R1 不是许可；R5 需独立满足条件且无更高优先级约束；无匹配时请求证据。
- Fig. 1、Fig. 2 已获本次单独网页图片公开授权。其余图使用已有公开汇总来源，Fig. 5 仅含既有授权的三个匿名示例。详见 [图表来源与范围](assets/figures/README.md)。
- 未加入论文 PDF、论文目录、`references/`、受限数组、刺激媒体或完整研究产物。
